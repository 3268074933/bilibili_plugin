# B站图片提取器

一个 Manifest V3 浏览器扩展（Edge / Chrome）：在 B 站视频页右下角提供「获取图片」按钮，抓取当前视频的封面、分 P 首帧与页面大图，在扩展内新标签页中展示、勾选并下载为 PNG。

## 功能

- 右下角悬浮「获取图片」按钮，不依赖 B 站页面自身的样式。
- 封面来源优先级：B 站 `view` 接口 → `og:image` / `itemprop="image"` → 播放器 `poster` → DOM 大图扫描。
- 自动去除 B 站 CDN 的缩放后缀（如 `@1280w_720h_1c.webp`）取原图，并按规范化 URL 去重。
- 结果页支持按来源筛选（全部 / 封面 / 页面图片 / 推荐）、全选、灯箱预览、单张下载。
- 统一转换为真正的 PNG 后下载，文件名自动清洗，同名文件自动加序号。
- 支持 SPA 切换视频、页面重绘、全屏播放与暗色模式。

## 目录结构

```text
shoping_plugin/
├── manifest.json
├── background/
│   └── service-worker.js   # 接口代理、消息路由、结果数据存储
├── content/
│   └── content.js          # 按钮挂载、抓取、SPA 兼容（样式内联在 Shadow DOM）
├── viewer/
│   ├── viewer.html         # 结果页
│   ├── viewer.css
│   └── viewer.js           # 渲染、勾选、灯箱、PNG 转换与下载
├── PROMPT.md               # 本项目的完整开发规格提示词
└── README.md
```

说明：按钮样式以 CSS 字符串形式内联在 `content/content.js`，通过 `adoptedStyleSheets` 注入 Shadow DOM，因此没有单独的 `content.css`。图标字段也未声明，浏览器会使用默认扩展图标；如需自定义，放入 `icons/` 并在 `manifest.json` 中补 `icons` 与 `action.default_icon`。

## 安装到 Edge

1. 打开 `edge://extensions`，开启左下角的「开发人员模式」。
2. 点击「加载解压缩的扩展」，选择本项目根目录（包含 `manifest.json` 的这一层）。
3. 打开任意 B 站视频页（`https://www.bilibili.com/video/BV...`），右下角会出现「获取图片」。

修改代码后，在扩展管理页点击该扩展的「重新加载」，再刷新 B 站页面。

## 使用

1. 在视频页点击「获取图片」，等待按钮变为「已获取 N 张」。
2. 扩展会打开新标签页，展示封面与页面大图。
3. 勾选需要的图片（或点「全选」），点击「下载选中」；也可直接「下载全部」。
4. 下载完成后，进度面板会显示成功与失败数量；失败项可单独重试。

默认文件名格式为 `<前缀>-<序号>-<标签>.png`，前缀取自视频标题，可在结果页顶部修改，修改结果会自动记住。

## 权限说明

| 权限 | 用途 |
|---|---|
| `storage` | 在内容脚本与结果页之间传递抓取结果，保存文件名前缀 |
| `downloads` | 保存转换后的 PNG 文件 |
| `host_permissions`（B 站与图片 CDN） | 请求视频元信息、读取图片二进制 |

扩展不读取 Cookie、不登录、不上传任何数据。

## 已知限制

- 抓取的是视频封面与页面静态图片，**不是视频抽帧**。
- B 站 `view` 接口可能因风控返回非 0 状态，此时自动降级为页面 meta / DOM 扫描，封面可能缺失或分辨率较低。
- 统一输出 PNG 需要 Canvas 重编码，会丢失 EXIF 等元数据，文件体积可能比原图大。
- 单张图片超过 16384 像素时浏览器画布无法处理，该张会被标记为失败。
- 结果数据保存在 `chrome.storage.session`，关闭浏览器后清空；结果页刷新仍可读取。
- 如果某些 CDN 图片返回 403（防盗链），当前实现会跳过并在失败清单中标注，不会卡住整个队列。
