产品介绍

不截图，不翻源码，
把页面里的好图一次带走。

这是一个挂在 B 站视频页右下角的小工具。它不改变 B 站原有界面，也不会自动爬取其他页面， 只在你点击「获取图片」时，读取当前视频的公开信息并扫描当前页面。

看看它能做什么
  1. 01

    打开任意 B 站视频页

    地址形如 bilibili.com/video/BV...，按钮会自动出现在右下角。

  2. 02

    点击「获取图片」

    插件读取视频元信息、封面与页面大图，去重排序后打开结果标签页。

  3. 03

    勾选并下载 PNG

    按来源筛选，预览大图，勾选需要的图片，统一转换并保存为 PNG。

核心功能

为「存图」这件小事，做足细节

从抓取、去重、筛选到下载，每一步都尽量少让你操心，也尽量不打扰页面本身。

封面精准提取

优先请求 B 站视频接口，失败时依次回退到页面 meta 与播放器封面。封面永远排在结果第一位。

  • view 接口
  • og:image
  • poster

分 P 首帧

读取各分 P 的首帧图，标记为「P1 首帧」「P2 首帧」，按分 P 顺序排列，找素材不用来回切页。

  • 多 P 视频
  • 按序排列

页面大图扫描

扫描当前页面中尺寸达标的图片，处理懒加载与 srcset，剥离 CDN 缩放后缀后按地址去重。

  • 400×200 阈值
  • 最大 srcset
  • URL 去重

筛选与灯箱预览

按全部、封面、页面图片、推荐切换视图，勾选状态不会被筛选清空；点击缩略图即可放大预览。

  • 来源筛选
  • 键盘切换
  • 暗色模式

批量下载 PNG

全选或逐张勾选，最多 3 张并发转换。失败自动重试一次，仍失败会列出原因并支持单独重试。

  • 3 并发
  • 进度显示
  • 失败重试

隐私优先

只申请存储与下载权限，不读取 Cookie、不调用需要登录态的接口，图片与标题始终留在你的电脑上。

安装步骤

一分钟装好，之后点一下就行

这是本地扩展，未上架应用商店。按下面的步骤加载解压后的文件夹即可。

  1. 1

    准备扩展文件

    下载或克隆项目并解压，确认文件夹根目录里能看到 manifest.json。

  2. 2

    打开扩展管理页

    Edge 地址栏输入 edge://extensions，Chrome 输入 chrome://extensions。

  3. 3

    开启开发人员模式

    在扩展管理页左下角或右上角找到「开发人员模式」开关并打开。

  4. 4

    加载解压缩的扩展

    点击「加载解压缩的扩展」，选择包含 manifest.json 的项目根目录。

  5. 5

    打开视频页开始使用

    进入任意 bilibili.com/video/BV... 页面，右下角出现「获取图片」按钮，点击即可。

系统要求

  • Microsoft Edge 或 Chrome
  • Chromium 内核 109 及以上
  • 无需 Node.js，无需构建
  • 无需注册账号

修改代码后，在扩展管理页点击该扩展的「重新加载」，再刷新 B 站页面即可生效。

本地扩展，安心使用

安装过程不会上传任何文件。插件只在 B 站视频页读取公开信息，图片转换与下载都在本机完成。

常见问题

你可能想先知道的事

关于收费、隐私、格式与能力边界，这里一次说清楚。

这个插件是免费的吗？

免费。它是本地运行的浏览器扩展，没有账号体系，也没有付费墙或隐藏次数限制。

会上传我的浏览数据或图片吗？

不会。插件不读取 Cookie、不登录、不调用需要账号态的接口，也不会把图片、URL 或视频标题发送到自建服务器。抓取结果只暂存在浏览器的会话存储中。

为什么下载后是 PNG？画质会变差吗？

统一输出 PNG 是为了让格式一致、方便继续编辑。源图是 JPEG / WebP 时会经过一次画布重编码，像素尺寸保持不变，但会丢失 EXIF 等元数据，文件体积也可能比原图大。这不是无损转换。

能从视频里截取画面吗？

不能。插件提取的是视频封面、分 P 首帧和当前页面上的静态大图，不做视频抽帧，也不下载视频或音频文件。

为什么有时抓不到封面或图片？

B 站接口可能因风控返回非零状态，此时插件会降级到页面 meta、播放器封面和 DOM 扫描，封面可能缺失或分辨率较低。遇到这种情况可以刷新页面后重试；单张图片请求失败也不会卡住整个下载队列。

支持哪些浏览器？支持淘宝、京东等电商页面吗？

支持 Edge 与 Chrome 等 Chromium 内核浏览器，建议 109 及以上版本。当前只匹配 B 站视频页，不处理淘宝、京东、拼多多等电商站点，也不是通用网页抓图工具。
